# Guía de estilo de programación

Este proyecto (my-app, dentro de YamidyValerinPrimerProyecto) debe programarse siguiendo las
reglas descritas en `F:\repos\Studies_Mobile\ESTILO_PROGRAMACION.md`.

Ese archivo documenta el estilo de programación de referencia (basado en el proyecto
Studies_Mobile): sintaxis, estructura de carpetas, convenciones de nombres, manejo de estado,
navegación con expo-router y nivel de complejidad a mantener.

Studies_Mobile es solo una referencia de estilo, no una fuente de código para copiar
literalmente. Antes de implementar cualquier funcionalidad nueva en este proyecto, revisa
ESTILO_PROGRAMACION.md y verifica que el código resultante cumpla esas reglas.

Al iniciar una sesión de Claude Code en este proyecto, indica explícitamente que seguirás las
reglas de ESTILO_PROGRAMACION.md antes de empezar a programar.
